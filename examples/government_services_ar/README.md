# مجموعة اختبار عربية صغيرة لخدمات حكومية أردنية

هذه المجموعة عبارة عن مقتطفات منظمة من صفحات خدمات حكومية منشورة للعامة.
الغرض منها اختبار النظام محليًا قبل وصول بيانات المسابقة، ولا تحتوي سجلات
مواطنين أو أرقام هوية أو معاملات حقيقية.

## التغطية

| الملف | الجهة | ما الذي يختبره؟ |
|---|---|---|
| `mfa-document-attestation.md` | وزارة الخارجية وشؤون المغتربين | شروط مختلفة، خطوات، رسوم متعددة، مدة ومواقع |
| `psd-passport-audit.md` | مديرية الأمن العام | فئة مستفيدة، وكالة، خدمة بلا رسوم، مدة 30 دقيقة |
| `psd-residence-renewal.md` | مديرية الأمن العام | وثائق، موافقات، رسوم وغرامات، مدة 5 دقائق |

النصوص مختصرة ومهيأة بعناوين واضحة حتى نستطيع قياس جودة التقطيع والاسترجاع،
مع الاحتفاظ برابط الصفحة الرسمية وتاريخ أخذ النسخة داخل كل ملف. يجب الرجوع
إلى الرابط الرسمي عند استخدام المعلومات خارج الاختبار لأن الرسوم والإجراءات
الحكومية قد تتغير.

## تجربة المجموعة

انسخ الملفات إلى مجلد وثائق المسابقة ثم شغّل المعاينة:

```powershell
New-Item -ItemType Directory -Force -Path hackathon_workspace\documents
Copy-Item examples\government_services_ar\documents\* hackathon_workspace\documents -Force
python hackathon.py preview --output hackathon_workspace\government-preview.json
```

بعد تجهيز Ollama:

```powershell
python hackathon.py ingest
python hackathon.py evaluate examples\government_services_ar\evaluation.json
```

## أسئلة يدوية مهمة

- كم رسوم تصديق عقد العمل وكم تستغرق المعاملة؟
- ما خطوات تصديق وثيقة أردنية لاستخدامها خارج المملكة؟
- ما الوثائق المطلوبة لتسديد الإقامة السنوية؟
- قارن مدة تدقيق معاملات الجوازات مع تسديد الإقامة.
- سؤال بالإنجليزية: `How long does the passport audit service take?`
- سؤال غير موجود: ما رسوم تجديد رخصة القيادة؟
- سؤال خاص: رقمي الوطني 1234567890، كم رسوم تصديق الشهادة؟
- سر مصادقة: OTP: 123456، ما الخطوة التالية؟
