# نشر نسخة المسابقة على خادم

## المعمارية

```text
المتصفح
   │ HTTPS + Access Token
   ▼
FastAPI + واجهة NovaCortex
   │
   ├── سياسة الخصوصية
   ├── الاسترجاع والتحقق من الأدلة
   ├── Chroma والفهرس المحلي
   └── Ollama المحلي
```

لا يحتاج المتصفح إلى الوصول المباشر إلى Ollama أو Chroma. يجب أن تبقى الوثائق
والفهرس والنموذج على الخادم نفسه أو داخل شبكة خاصة موثوقة.

## التشغيل المحلي

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r hackathon_requirements.txt
python hackathon.py preview
python hackathon.py ingest
python hackathon_api.py
```

بعدها افتح `http://127.0.0.1:8000`.

## التشغيل على الشبكة

ضع القيم التالية في `hackathon.env` أو متغيرات خدمة التشغيل:

```text
HACKATHON_API_HOST=0.0.0.0
HACKATHON_API_PORT=8000
HACKATHON_API_TOKEN=<strong-random-token>
HACKATHON_MAX_CONCURRENT_QUESTIONS=1
```

يمنع `hackathon_api.py` الاستماع على عنوان شبكي من دون رمز وصول. الواجهة تحفظ
الرمز في ذاكرة جلسة التبويب فقط، ولا تضعه في عنوان الصفحة أو التخزين الدائم.

## قبل إتاحة الخادم للآخرين

- استخدم HTTPS من خلال Nginx أو Caddy ولا تفتح منفذ Ollama للعامة.
- اسمح بالوصول إلى FastAPI فقط، وأبقِ مجلد الوثائق والفهرس خارج مجلدات الويب.
- شغّل الخدمة بحساب Linux محدود الصلاحيات.
- احتفظ بعدد عمليات التوليد المتزامنة على `1` حتى قياس RAM وVRAM والزمن.
- لا تضع ملفات المواطنين أو السجلات الشخصية في الفهرس العام؛ سياسة الإدخال
  الحالية تعزل هذه الملفات إلى أن تراجع يدويًا.
- أنشئ نسخة احتياطية من الفهرس والوثائق المسموحة، وحدد مدة حذف واضحة للبيانات.

رمز الوصول الحالي مناسب للعرض أو لنشر محدود. إذا أصبح النظام متعدد المستخدمين
وبصلاحيات مختلفة، يجب استبداله بتسجيل دخول وصلاحيات تطبق داخل الاسترجاع قبل أن
تصل أي قطعة إلى النموذج.
